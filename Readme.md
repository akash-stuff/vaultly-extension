## 1. Load the Extension

1. Open **Google Chrome**.
2. Go to `chrome://extensions/`.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked**.
5. Select the `extension/` folder from the project.

---

## 2. Pin the Extension

1. Click the **Extensions** (🧩) icon.
2. Click the **Pin** icon next to **Vaultly**.

---

## 3. Sign In

1. Click the Vaultly extension icon.
2. Log in using your **existing Vaultly account**.

> **Note:** User registration is available only through the Vaultly Web Dashboard.

---

## Updating the Extension

After making changes to the extension files:

1. Open `chrome://extensions/`.
2. Click **Reload** on the Vaultly extension.
